# Component States

Every interactive control needs default, hover, focus-visible, disabled, loading, error, and empty where data can be missing.

| State | Requirement |
| --- | --- |
| empty | Teach the next action; no "nothing here" dead ends |
| loading | Immediate feedback; skeleton or progress; keep layout stable |
| error | Say what failed and how to recover |
| success | Confirm the job completed |
| permission | Explain why and how to get access |
| reduced-motion | No essential info only in motion |

Copy is UX. Primary CTAs must be real verbs, not lorem.
