# Landing Page Anatomy

One offer per page. Hierarchy: proof of job-to-be-done, then action.

1. Nav: identity, 3-5 links, one primary CTA
2. Hero: specific promise, supporting line, one primary action, real product proof (not a generic 3D blob)
3. Proof: logos only if real; quotes with names; metrics that can be checked
4. How it works: 3-5 steps with uneven layout, not identical cards
5. Offer / pricing: comparable plans, honest limits
6. FAQ and footer

Do not center every block. Vary span, media, and whitespace. See `patterns.md` and `anti-slop.md`.
